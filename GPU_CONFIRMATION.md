# Plato GPU confirmation protocol · 26 November 2026

The question is whether a map fitted to familiar facts carries a newly randomized category from one frozen model family to another. This addendum retains the original factual, contextual, accuracy and resource specifications in [the protocol](plato/protocol.md). It was written after the hardware benchmarks and a partial CPU prompt audit, ahead of the GPU control results and either private held-out cohort. Previously reported hardware timings measured one warm world. CPU validation data are excluded from GPU accuracy estimates.

## Outcomes and independent units

Qwen2.5-1.5B on L40S and Pythia-1.4B-deduped on L4 each send to SmolLM2-1.7B. Each world has eight changes to a private category and two independently assigned rulebooks with different destinations for every category. Reuse the exact serialized packet under both rulebooks. Define joint success per category as getting both destinations right. Report the mean of these eight indicators first within each world, then across worlds. Run 10,000 paired bootstrap resamples of entire worlds. Keep all categories, arms and books together. Report each sender and cohort separately.

Worlds come from the published v1 generator. Original validation uses the 64 validation indices 0–63. Development uses eight bench worlds starting at 10000. Any amended interface uses a single fresh validation cohort at validation indices 10000–10063. Original held-out indices are test 0–249. Confirmation uses **test 100000–102499 inclusive**, the same 2,500 new worlds for both senders. The 64 robustness worlds keep their original separate template and seed namespace. Keep test and confirmation unread until qualification. Commit selection and seeds before either cohort is evaluated. Complete both held-out cohorts for qualifying pairs regardless of effect direction on the first.

## Order and decisions

1. Run the original positive controls in GPU BF16 with greedy generation and exact first-nonempty-line scoring. Require sender retrieval and receiver full-evidence accuracy each ≥95%, receiver own-state patch accuracy ≥80% under each book, and maximum absolute identity-logit error ≤0.0001. Record every preregistered candidate receiver layer where factual selection has yet to take place. An essential text-control failure or failure at every possible patch layer disqualifies the original interface.
2. For an interface repair, compare a finite set of prompts on development worlds only. Keep evidence, model revisions, full-line scoring, channel width and separation of evidence and rulebook fixed. Freeze one nominated prompt and a deterministic selection rule. Report the original result and all development candidates. If an amendment is necessary, evaluate the nominated format once on the fresh validation cohort and retain raw completions. A pair failing a necessary gate stops before either held-out cohort. A candidate-layer pass is provisional until the layer selected on factual validation also passes.
3. For a surviving pair, fit the centered, scaled factual Procrustes map on subject-disjoint mutually recalled CounterFact true answers. Select layers only on factual validation. Fit the separate contextual diagnostic on the 512 contextual training worlds. Verify gates on the selected layers and record the hash of the final protocol, maps and predictions. Before scaling, time a multi-world validation shard and verify compressed output size, bounded remaining cost, and shard resumability.
4. Report factual, wrong factual, contextual, wrong contextual, no message, receiver own state, full evidence, generated word and one-byte code. Declare a strong result only with ≥75% factual accuracy on each book, ≥20 percentage points over the wrong vector with positive lower paired 95% bounds on each, and ≥60% joint success with identical packets. Call it replicated only if both senders meet these criteria on the fresh confirmation cohort. Smaller effects and failed controls are publishable. A gate failure cannot establish that the transfer mechanism fails.
5. Publish raw responses, exact prompts, reconstructible rulebooks, packet hashes when applicable, independently rescored counts and provider gross usage for the identified jobs. Preserve both cohorts' sealed or completed status per pair. Reproduce the report from the public archive. The combined spending ceiling is $170 in Modal credits including outstanding reservations. Complete paid work before the verified cutoff.
